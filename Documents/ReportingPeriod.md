**Use Case: دوره گزارشگری**

**1\. مشخصات**

| **عنوان**    | **مقدار**     |
| ------------ | ------------- |
| نام Use Case | دوره گزارشگری |
| Actor        | کاربر مجاز    |
| محل          | اطلاعات پایه  |

**2\. هدف**

امکان ایجاد و مدیریت دوره‌های گزارشگری در سیستم.

**4\. لیست دوره‌های گزارشگری**

لیست فقط دوره‌های گزارشگری مربوط به دوره مالی جاری را نمایش می‌دهد.

**ستون‌ها**

- کد دوره
- عنوان
- از تاریخ
- تا تاریخ
- وضعیت

**عملیات**

- جدید
- ویرایش
- حذف
- بستن دوره
- بازکردن دوره

**5\. ایجاد دوره**

**جریان اصلی**

1. کاربر گزینه «جدید» را انتخاب می‌کند.
2. سیستم دوره مالی جاری را نمایش می‌دهد.
3. سیستم تاریخ شروع دوره را تعیین می‌کند.
4. کاربر کد دوره را وارد می‌کند.
5. کاربر عنوان دوره را وارد می‌کند.
6. کاربر تاریخ پایان را وارد می‌کند.
7. کاربر اطلاعات را ذخیره می‌کند.
8. سیستم دوره را با وضعیت «باز» ایجاد می‌کند.

**تعیین تاریخ شروع**

اگر اولین دوره گزارشگری باشد:

از تاریخ = تاریخ شروع دوره مالی

در غیر این صورت:

از تاریخ = یک روز بعد از تاریخ پایان آخرین دوره گزارشگری

**6\. ویرایش دوره**

1. کاربر یک دوره را انتخاب می‌کند.
2. گزینه «ویرایش» را انتخاب می‌کند.
3. سیستم فرم را نمایش می‌دهد.
4. کاربر اطلاعات قابل ویرایش را اصلاح می‌کند.
5. سیستم کنترل‌های لازم را انجام می‌دهد.
6. اطلاعات ذخیره می‌شود.

**از تاریخ قابل ویرایش نیست.**

دوره بسته قابل ویرایش نیست.

**7\. حذف دوره**

1. کاربر یک دوره را انتخاب می‌کند.
2. گزینه «حذف» را انتخاب می‌کند.
3. سیستم امکان حذف را کنترل می‌کند.
4. در صورت مجاز بودن، دوره حذف می‌شود.

دوره مورد استفاده قرارگرفته قابل حذف نیست.

**8\. بستن دوره**

1. کاربر یک دوره باز را انتخاب می‌کند.
2. گزینه «بستن دوره» را انتخاب می‌کند.
3. سیستم تأیید کاربر را دریافت می‌کند.
4. وضعیت دوره به «بسته» تغییر می‌کند.

دوره بسته قابل ویرایش و حذف نیست.

**9\. بازکردن دوره**

1. کاربر یک دوره بسته را انتخاب می‌کند.
2. گزینه «بازکردن دوره» را انتخاب می‌کند.
3. سیستم امکان بازکردن را کنترل می‌کند.
4. در صورت مجاز بودن، وضعیت دوره به «باز» تغییر می‌کند.

**10\. کنترل‌های فرم**

- کد دوره الزامی است.
- عنوان دوره الزامی است.
- تاریخ پایان الزامی است.
- کد دوره نباید تکراری باشد.
- تاریخ پایان نباید قبل از تاریخ شروع باشد.
- تاریخ پایان نباید خارج از محدوده دوره مالی جاری باشد.
- دوره‌ها نباید با یکدیگر هم‌پوشانی داشته باشند.
- دوره بسته قابل ویرایش نیست.
- دوره بسته قابل حذف نیست.
- دوره مورد استفاده قرارگرفته قابل حذف نیست.
- تاریخ شروع توسط سیستم تعیین می‌شود و قابل ویرایش نیست.
- دوره جدید با وضعیت «باز» ایجاد می‌شود.

**11\. وضعیت‌ها**

باز

بسته

**12\. پیام‌های خطا**

**تاریخ نامعتبر:**

تاریخ پایان نمی‌تواند قبل از تاریخ شروع دوره باشد.

**خارج از محدوده دوره مالی:**

تاریخ پایان باید در محدوده دوره مالی جاری قرار داشته باشد.

**کد تکراری:**

کد دوره قبلاً استفاده شده است.

**دوره بسته:**

دوره بسته قابل ویرایش نیست.

**حذف غیرمجاز:**

این دوره قابل حذف نیست.

**بازکردن غیرمجاز:**

بازکردن این دوره امکان‌پذیر نیست.
