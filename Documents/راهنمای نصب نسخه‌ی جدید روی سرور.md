# راهنمای نصب نسخه‌ی جدید روی سرور

این راهنما برای **نصب تازه‌ی** برنامه روی یک سرور لینوکس (مشتری، آزمایشی یا Staging) است. به‌روزرسانی نصب موجود جداست (آخر همین فایل).

مقادیر ثابت این راهنما:

| مورد | مقدار |
|---|---|
| ریجستری | `repo.saam.ir/saam-ai` |
| فایل‌های لازم از پروژه | `docker-compose.prod.yml` و `.env.example` (ریشه‌ی پروژه) |
| نسخه | همان نسخه‌ی منتشرشده (مثلاً `1.54.0`)؛ تگ `latest` عمداً در ریجستری نیست، پس نسخه را باید دقیق بنویسید |

**اصل کار:** هر نصب یک پوشه‌ی جدا دارد (مثلاً `/opt/erp-<نام>`). نام پوشه نام پروژه‌ی compose را می‌سازد، پس دیتابیس و پشتیبان هر نصب جدا می‌ماند و چند نصب (یا برنامه‌ی دیگر) کنار هم قاطی نمی‌شوند. فقط **پورت‌ها** باید با هم برخورد نکنند.

---

## ۰) پیش‌نیازها (یک‌بار برای هر سرور)

روی سرور باید Docker و Docker Compose v2 باشد و سرور به `repo.saam.ir` برسد.

```bash
docker --version && docker compose version
```

```bash
curl -sS -m 15 -o /dev/null -w "%{http_code}\n" https://repo.saam.ir/v2/
```

خروجی دومی باید `401` باشد.

اگر سرور به Docker Hub دسترسی ندارد (مثلاً داخل ایران)، ایمیج دیتابیس را هم از ریجستری خودمان می‌گیریم؛ بند «ایمیج دیتابیس» پایین را ببینید.

## ۱) پورت‌ها را انتخاب کنید

پورت‌های پیش‌فرض **۴۰۰۰** (API) و **۵۱۷۳** (وب) هستند. اگر برنامه‌ی دیگری روی همان سرور هست، ببینید چه پورت‌هایی گرفته است:

```bash
ss -ltn | grep -E ':(4000|5173)\b' || echo "پورت‌های پیش‌فرض آزادند"
```

اگر اشغال بودند، پورت‌های دیگری انتخاب کنید (مثلاً **۴۱۰۰** و **۵۲۷۳**) و در مرحله‌ی ۳ در `.env` بگذارید.

## ۲) ساخت پوشه‌ی نصب و فرستادن فایل‌ها

روی سرور:

```bash
sudo mkdir -p /opt/erp-NAME && sudo chown $USER /opt/erp-NAME
```

(به‌جای `NAME` یک نام کوتاه انگلیسی بگذارید، مثلاً `erp-newapp`.)

روی کامپیوتر توسعه (PowerShell، در `E:\accounting-erp`):

```bash
scp docker-compose.prod.yml .env.example USER@SERVER:/opt/erp-NAME/
```

## ۳) ساخت `.env`

روی سرور:

```bash
cd /opt/erp-NAME && cp .env.example .env
```

سه رمز تصادفی بسازید (هر دستور یک مقدار می‌دهد؛ برای هر کدام یکی بردارید):

```bash
openssl rand -base64 32
```

```bash
openssl rand -hex 32
```

فایل را باز کنید (`nano .env`) و این مقادیر را بنویسید (خط‌های `#` را اگر لازم بود با برداشتن `#` فعال کنید):

```
POSTGRES_PASSWORD=<رمز تصادفی ۱>
JWT_SECRET=<رمز تصادفی ۲>
UPDATER_TOKEN=<رمز hex>
ERP_REGISTRY=repo.saam.ir/saam-ai
ERP_VERSION=1.54.0
```

اگر پورت‌ها را عوض کردید (مثال ۴۱۰۰ و ۵۲۷۳):

```
BACKEND_PORT=4100
FRONTEND_PORT=5273
VITE_API_URL=http://<آدرس-سرور>:4100/api
```

نکته‌ها:
- `JWT_SECRET` را بعد از اولین استفاده عوض نکنید.
- `ERP_VERSION` را از صفحه‌ی `/management` یک نصب دیگر یا از فهرست نسخه‌های ریجستری بردارید؛ همیشه نسخه‌ی کامل بنویسید (نه `latest`).
- اگر آدرس برنامه با دامنه و پشت پراکسی باز می‌شود، `ALLOWED_HOSTS` و `VITE_API_URL=/api` را هم طبق توضیح داخل `.env.example` بگذارید.

### ایمیج دیتابیس (فقط اگر سرور به Docker Hub نمی‌رسد)

روی کامپیوتری که اینترنت آزاد دارد، یک‌بار:

```bash
docker pull postgres:16-alpine
```

```bash
docker tag postgres:16-alpine repo.saam.ir/saam-ai/postgres:16-alpine
```

```bash
docker push repo.saam.ir/saam-ai/postgres:16-alpine
```

بعد در `.env` سرور بنویسید: `DB_IMAGE=repo.saam.ir/saam-ai/postgres:16-alpine`

## ۴) ورود به ریجستری و بالا آوردن

روی سرور، در `/opt/erp-NAME`:

```bash
docker login repo.saam.ir
```

(نام کاربری و رمز حساب فقط‌خواندنی ریجستری را بدهید.)

```bash
docker compose -f docker-compose.prod.yml pull
```

```bash
docker compose -f docker-compose.prod.yml up -d
```

اولین بار backend مهاجرت‌های دیتابیس و seed را اجرا می‌کند و چند ده ثانیه طول می‌کشد. وضعیت:

```bash
docker compose -f docker-compose.prod.yml ps
```

```bash
docker compose -f docker-compose.prod.yml logs --tail 30 backend
```

سالم بودن API:

```bash
curl -s http://localhost:4000/api/health
```

(اگر `BACKEND_PORT` را عوض کرده‌اید، همان پورت را بزنید.) باید `{"ok":true}` بدهد.

## ۵) بعد از بالا آمدن

۱. **لایسنس (اجباری):** در مرورگر `http://<آدرس-سرور>:<پورت-وب>/management` را باز کنید. فایل «اطلاعات سرور (XML)» را دانلود کنید و در «مدیریت لایسنس» (license-manager) برای این سرور لایسنس صادر کنید؛ سپس فایل لایسنس و رمز مدیریت را در همان صفحه آپلود کنید. بدون لایسنس، برنامه قفل است.

۲. **ورود به برنامه:** `http://<آدرس-سرور>:<پورت-وب>` — کاربر پیش‌فرض seed: موبایل `0999999999` و رمز `Admin@123`. **رمز را همان لحظه عوض کنید** (آیکون پروفایل بالا).

۳. **پشتیبان‌گیری:** از `/management` › تنظیمات پشتیبان‌گیری سیاست خودکار را فعال کنید.

۴. **به‌روزرسانی از داخل برنامه:** در `/management` › به‌روزرسانی، آدرس ریجستری `repo.saam.ir/saam-ai`، نام کاربری و رمز حساب فقط‌خواندنی را بدهید و «ذخیره‌ی اتصال» را بزنید. از این به بعد نسخه‌های جدید از همین صفحه نصب می‌شوند.

۵. **فایروال:** پورت وب (و پورت API، اگر مرورگر مستقیم به آن می‌رسد) باید برای کاربران باز باشد. پورت دیتابیس عمداً بسته است.

اختیاری (روی همین نصب فقط اگر لازم است): زمان‌بند کارها `SCHEDULER_ENABLED=true`، ارسال مودیان `TAX_TRANSPORT_ENABLED=true` (قانونی و واقعی است؛ روی سرور آزمایشی روشن نکنید).

## به‌روزرسانی یک نصب موجود

از `/management` › به‌روزرسانی، «بررسی دوباره» و بعد «به‌روزرسانی به این نسخه». نیازی نیست نسخه‌های میانی نصب شوند (تغییرات تجمعی‌اند و مهاجرت‌ها پشت‌سرهم اجرا می‌شوند). سرویس updater قبل از شروع پشتیبان می‌گیرد و در صورت شکست خودش برمی‌گردد.

اگر `/management` در دسترس نیست، دستی (در پوشه‌ی نصب):

```bash
sed -i 's/^ERP_VERSION=.*/ERP_VERSION=<نسخه>/' .env
```

```bash
docker compose -f docker-compose.prod.yml pull && docker compose -f docker-compose.prod.yml up -d
```

(پیش از دستی‌کردن، از دیتابیس پشتیبان بگیرید.)

## عیب‌یابی سریع

| نشانه | علت و راه‌حل |
|---|---|
| `manifest unknown` / `not found` موقع pull | `ERP_VERSION` در `.env` اشتباه یا خالی است (تگ `latest` وجود ندارد) |
| `port is already allocated` | پورت اشغال است؛ `BACKEND_PORT`/`FRONTEND_PORT` را عوض و دوباره `up -d` بزنید |
| صفحه باز می‌شود ولی ورود/داده نمی‌آید | `VITE_API_URL` با پورت واقعی API نمی‌خواند؛ پس از اصلاح، `up -d` بزنید |
| همه‌ی درخواست‌ها `LICENSE_REQUIRED` | لایسنس فعال نشده؛ بند ۵-۱ |
| `denied` موقع pull | `docker login repo.saam.ir` انجام نشده یا حساب دسترسی ندارد |
| backend بالا نمی‌آید | `docker compose -f docker-compose.prod.yml logs --tail 50 backend` را بخوانید (معمولاً رمز/`DATABASE_URL` یا مهاجرت) |
